# CS50P – Solutions


I have tried my best to provide correct and accurate solutions, make sure to check by yourself.

This repository contains my solutions to problem sets from [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) by Harvard University.

I'm using this course to improve my Python programming skills, problem-solving, and understanding of programming fundamentals.

## Repository Structure

* Each `week` folder contains the files for that week's coursework.
* Each week has a `pset` folder containing the problem set solutions.
* Other related files, such as CSV, TXT, and GIF files, are stored alongside the problem set folder when required.

Example:

```text
week6/
├── pset6/
│   ├── lines.py
│   └── pizza.py
├── regular.csv
├── sicilian.csv
└── ...
```
